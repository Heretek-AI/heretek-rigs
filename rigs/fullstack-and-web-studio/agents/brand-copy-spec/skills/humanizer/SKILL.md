# Humanizer Copywriting & Documentation Refactoring Protocol

Follow these procedural heuristics when drafting or refining brand copy, user documentation, and microcopy:

1. **AI Tell Pattern Detection**:
   Scan text for common synthetic language patterns:
   - Overused Latinate buzzwords: *delve, tapestry, landscape, pivotal, testament, seamless, beacon, leverage*.
   - Rhetorical triplets (*safe, secure, and reliable*) and artificial superlatives.
   - Excessive em-dashes and colon-separated intro clauses.
   - Symmetrical paragraph structures and sycophantic summary conclusions (*In conclusion, by leveraging...*).

2. **Stylistic Transformation Heuristics**:
   - Replace abstract nouns with concrete physical actions and direct verbs.
   - Vary sentence cadence: alternate punchy short assertions (3–7 words) with informative explanatory structures.
   - Express technical concepts with precision rather than decorative filler.
   - Remove self-referential conversational fluff (*Certainly! Here is...*).

3. **Readability & Integrity Gate**:
   - Verify that all technical facts, code examples, API parameters, and constraints remain 100% unaltered.
   - Confirm copy communicates directly and respectfully with professional engineers.
