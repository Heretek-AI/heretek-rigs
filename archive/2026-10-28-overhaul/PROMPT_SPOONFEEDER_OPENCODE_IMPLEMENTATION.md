## 4. Verified Runtime & Security Facts

1. **OpenRig CLI (`rig`)**:
   - `rig spec validate <rig.yaml> --json` and `rig bundle check <dir> --json` run **offline** (`rig bundle check --json` outputs `[]` when there are 0 findings).
   - `rig agent validate <agent.yaml> --json` and `rig spec preflight <rig.yaml> --json` require a running daemon (`rig daemon start --no-kernel`).
2. **OpenCode Go & Pi 1.3.0**:
   - `opencode-go/muse-spark-1.3-contributor` is built into `@earendil-works/pi-coding-agent@1.3.0` (`api: "openai-responses"`, `baseUrl: "https://opencode.ai/inference/go/v1"`, `contextWindow: 1048576`, `maxTokens: 131072`, thinking levels `off`, `minimal`, `low`, `medium`, `high`, `xhigh`).
   - OpenRig's `buildPiChildEnv` strips `OPENCODE_API_KEY` from `runtime: pi` seats. Each seat receives `<agentDir>/auth.json` (`0600`) with `{"opencode-go":{"type":"api_key","key":"!cat <SECRETS>/opencode-go.key"}}` and `<agentDir>/models.json`.
3. **`@gotgenes/pi-permission-system@41.0.0` Enforcement & Path Traversal Guard**:
   - Loaded per seat via `settings.json` `packages`, reading `<agentDir>/extensions/pi-permission-system/config.json`.
   - Inside each rule map (`path_write`, `path`, `bash`, `mcp`), **the last matching rule wins**.
   - Without `"*..*": "deny"` at the end of `path_write`, `write docs/../evil.md` matches `"docs/*": "allow"` and escapes to the repository root. Placing `"*..*": "deny"` last blocks all `..` traversal.
   - Extension tools (`classifyToolKind() === "extension"`) do not pass through `path_write`. Therefore, mutating tools from `pi-lsp-extension@1.4.0` (`code_rewrite`, `lsp_rename`, `lsp_code_actions`) are explicitly set to `"deny"` across all 51 seats while read-only AST/LSP tools (`ast_grep`, `ast_search`, `code_overview`, `lsp_diagnostics`, `lsp_hover`, `lsp_definition`, `lsp_references`, `lsp_symbols`, `lsp_completions`) are set to `"allow"` on the 21 code-analysis/builder seats.

USAGE = """usage: render-seat.py --role <role-id> --rig <rig-id> --pod <pod-id> [options]
  --member <id>            member id in the rig (default: the role id)
  --fleet <file>           default fleet/fleet.yaml
  --mcp <file>             default fleet/mcp-servers.yaml
  --charter <file>         default specs/agents/<domain>/<role>/guidance/role.md
  --out <dir>              default $OPENRIG_HOME/state/pi/<pod>-<member>@<rig>/agent
  --model-provider <p>     default opencode-go (tests use: mock)
  --model-id <id>          default muse-spark-1.3-contributor (tests use: mock-model)
  --allow-missing-secrets  write servers whose secret files are missing with "enabled": false
  --dry-run                print the rendered files as JSON instead of writing them
  --help"""

READONLY_AST_LSP_TOOLS = [
    "ast_grep",
    "ast_search",
    "code_overview",
    "lsp_diagnostics",
    "lsp_hover",
    "lsp_definition",
    "lsp_references",
    "lsp_symbols",
    "lsp_completions",
]

MUTATING_AST_LSP_TOOLS = [
    "code_rewrite",
    "lsp_rename",
    "lsp_code_actions",
]


def die(msg: str) -> None:
    print(f"error: {msg}", file=sys.stderr)
    sys.exit(2)


def build_seat_files(
    role_id: str,
    rig_id: str,
    pod_id: str,
    member_id: str,
    fleet_data: dict,
    mcp_catalog: dict,
    tools_dir: str,
    secrets_dir: str,
    seat_dir: str,
    charter_text: str,
    model_provider: str = "opencode-go",
    model_id: str = "muse-spark-1.3-contributor",
    allow_missing_secrets: bool = False,
    check_secret_fs: bool = True,
) -> dict:
    if role_id not in fleet_data.get("roles", {}):
        die(f"unknown role {role_id}")
    role = fleet_data["roles"][role_id]

    for ident in (pod_id, member_id):
        if re.search(r"[.@]", ident):
            die(f"pod/member ids must not contain '.' or '@': {ident}")

    session = f"{pod_id}-{member_id}@{rig_id}"
    pps_pkg = str(Path(tools_dir) / "pi-packages/node_modules/@gotgenes/pi-permission-system")

    def secret_ok(filename: str) -> bool:
        if not check_secret_fs:
            return False
        p = Path(secrets_dir) / filename
        if not p.exists():
            return False
        mode = p.stat().st_mode & 0o777
        if mode & 0o077:
            die(f"{p} is mode {oct(mode)[2:]}; run: chmod 600 {p}")
        return True

    def subst(val):
        if isinstance(val, str):
            return (
                val.replace("@TOOLS@", tools_dir)
                .replace("@SECRETS@", secrets_dir)
                .replace("@SEAT@", seat_dir)
            )
        return val

    files = {}

    # 1. auth.json & models.json
    if model_provider == "opencode-go":
        has_key = secret_ok("opencode-go.key")
        if not has_key and not allow_missing_secrets:
            die(f"missing {Path(secrets_dir) / 'opencode-go.key'} (chmod 600)")
        files["auth.json"] = {
            "opencode-go": {
                "type": "api_key",
                "key": f"!cat {Path(secrets_dir) / 'opencode-go.key'}",
            }
        }
        files["models.json"] = {
            "providers": {
                "opencode-go": {
                    "api": "openai-responses",
                    "baseUrl": "https://opencode.ai/inference/go/v1",
                    "models": [
                        {
                            "id": "muse-spark-1.3-contributor",
                            "name": "Muse Spark 1.3 Contributor",
                            "reasoning": True,
                            "input": ["text", "image"],
                            "thinkingLevelMap": {
                                "off": None,
                                "minimal": "minimal",
                                "low": "low",
                                "medium": "medium",
                                "high": "high",
                                "xhigh": "xhigh",
                                "max": None,
                            },
                            "contextWindow": 1048576,
                            "maxTokens": 131072,
                            "cost": {"input": 0.10, "output": 0.20, "cacheRead": 0.002, "cacheWrite": 0},
                            "compat": {
                                "supportsDeveloperRole": True,
                                "sendSessionIdHeader": True,
                                "supportsLongCacheRetention": True,
                                "sessionAffinityFormat": "openai-nosession",
                            },
                        }
                    ],
                }
            }
        }

    # 2. mcp.json
    mcp_servers = {}
    mcp_allow = {"*": "deny"}
    deferred = False
    for b in role.get("mcp", []):
        srv_name = b["server"]
        if srv_name not in mcp_catalog:
            die(f"role {role_id} binds unknown MCP server {srv_name}")
        s = mcp_catalog[srv_name]
        need = s.get("required_secrets", [])
        missing = [f for f in need if not secret_ok(f)]
        toolset = b.get("toolset", "")
        entry = {
            "description": subst(s["description"]).replace("{toolset}", toolset),
            "exposure": s["exposure"],
        }
        if s["transport"] == "http":
            entry["url"] = s["url_template"].replace("{toolset}", toolset or "repos")
            entry["headers"] = {k: subst(v) for k, v in s.get("headers", {}).items()}
        else:
            entry["command"] = subst(s["command"])
            entry["args"] = [subst(x) for x in s.get("args", [])]
            if any(str(x).startswith("!") for x in entry["args"]):
                die(f"{srv_name}: Pi never expands !command in args")
            if "env" in s:
                entry["env"] = {k: subst(v) for k, v in s["env"].items()}

        for opt_sec in s.get("optional_secrets", []):
            if not secret_ok(opt_sec) and "env" in entry:
                for k in list(entry["env"].keys()):
                    if opt_sec in str(entry["env"][k]):
                        del entry["env"][k]

        if missing:
            if not allow_missing_secrets:
                missing_paths = ", ".join(str(Path(secrets_dir) / f) for f in missing)
                die(f"{srv_name} needs {missing_paths}")
            entry["enabled"] = False
            if check_secret_fs:
                print(
                    f"warn: {session}: {srv_name} disabled, missing secrets: {', '.join(missing)}",
                    file=sys.stderr,
                )

        mcp_servers[srv_name] = entry
        mcp_allow[srv_name] = "allow"
        if s["exposure"] == "deferred":
            deferred = True

    files["mcp.json"] = {"mcpServers": mcp_servers}

    # 3. settings.json
    tools = ["read", "grep", "find", "ls", "bash", "edit", "write"]
    if deferred:
        tools.append("tool_search")

    packages = [pps_pkg]
    role_pkgs = role.get("pi_packages", ["@gotgenes/pi-permission-system@41.0.0"])
    has_ast_lsp = any(p.startswith(("pi-lsp-extension", "pi-ast-grep")) for p in role_pkgs)
    for pkg in role_pkgs:
        if pkg.startswith("@gotgenes/pi-permission-system"):
            continue
        pkg_name = pkg.split("@")[0] if not pkg.startswith("@") else "@" + pkg[1:].split("@")[0]
        candidate = Path(tools_dir) / "pi-packages/node_modules" / pkg_name
        if candidate.exists():
            packages.append(str(candidate))

    files["settings.json"] = {
        "defaultProvider": model_provider,
        "defaultModel": model_id,
        "defaultThinkingLevel": role["thinking"],
        "defaultTools": tools,
        "packages": packages,
        "quietStartup": True,
    }

    # 4. extensions/pi-permission-system/config.json
    # Last matching rule wins inside each map; guards MUST go LAST.
    path_write = {"*": "deny"}
    for g in role["permissions"]["path_write"]:
        path_write[g] = "allow"
    for guard_k in (".git/*", "*/.git/*", "AGENTS.md", ".pi/*", ".agents/*", "*..*"):
        path_write.pop(guard_k, None)
        path_write[guard_k] = "deny"

    bash_map = {"*": "deny"}
    for p in role["permissions"]["bash_allow"]:
        bash_map[p] = "allow"

    permission = {
        "*": "deny",
        "read": "allow",
        "grep": "allow",
        "find": "allow",
        "ls": "allow",
        "write": "allow",
        "edit": "allow",
    }
    if has_ast_lsp:
        for t_ro in READONLY_AST_LSP_TOOLS:
            permission[t_ro] = "allow"
    for t_mut in MUTATING_AST_LSP_TOOLS:
        permission[t_mut] = "deny"
    if deferred:
        permission["tool_search"] = "allow"

    permission["bash"] = bash_map
    permission["path"] = {
        "*": "allow",
        "*.env": "deny",
        "*.env.*": "deny",
        "*.env.example": "allow",
        "*.pem": "deny",
        "*.key": "deny",
        "*id_rsa*": "deny",
        "*kubeconfig*": "deny",
        "*/secrets/*": "deny",
        "*..*": "deny",
    }
    permission["path_write"] = path_write
    permission["mcp"] = mcp_allow
    permission["external_directory"] = "deny"

    files["extensions/pi-permission-system/config.json"] = {
        "promptTimeoutMs": 60000,
        "permission": permission,
    }

    # 5. AGENTS.md: role charter + seat block (never use guidance_merge on shared cwd)
    esc = role.get("reports_to")
    esc_line = (
        f'- Escalate with: `rig send {esc["address"]} "<message>"` ({esc["role"]}{", same rig" if esc.get("same_rig") else ", other rig"}).'
        if esc
        else "- You are the top of the escalation chain; escalate to the human."
    )
    writable_str = ", ".join(f"`{g}`" for g in role["permissions"]["path_write"]) or "none"
    addr_block = "\n".join(
        [
            "## Seat",
            "",
            f"- You are `{role_id}` in seat `{session}` (rig `{rig_id}`, pod `{pod_id}`).",
            f"- Model: {model_provider}/{model_id}, thinking {role['thinking']}. Recorded policy: {role['permission_policy']}.",
            esc_line,
            f"- Writable paths: {writable_str}. Everything else is read-only.",
            "",
        ]
    )
    files["AGENTS.md"] = charter_text.rstrip() + "\n\n" + addr_block
    return files


def main() -> None:
    if "--help" in sys.argv or "-h" in sys.argv:
        print(USAGE)
        sys.exit(0)

    parser = argparse.ArgumentParser(add_help=False)
    parser.add_argument("--role")
    parser.add_argument("--rig")
    parser.add_argument("--pod")
    parser.add_argument("--member")
    parser.add_argument("--fleet", default="fleet/fleet.yaml")
    parser.add_argument("--mcp", default="fleet/mcp-servers.yaml")
    parser.add_argument("--charter")
    parser.add_argument("--out")
    parser.add_argument("--model-provider", default="opencode-go")
    parser.add_argument("--model-id", default="muse-spark-1.3-contributor")
    parser.add_argument("--allow-missing-secrets", action="store_true")
    parser.add_argument("--dry-run", action="store_true")
    args, unknown = parser.parse_known_args()
    if unknown:
        die(f"unknown arguments: {' '.join(unknown)}\n{USAGE}")
    for req in ("role", "rig", "pod"):
        if not getattr(args, req):
            die(f"--{req} is required\n{USAGE}")

    home = Path.home()
    openrig_home = Path(os.environ.get("OPENRIG_HOME", str(home / ".openrig"))).resolve()
    tools_dir = str(Path(os.environ.get("HERETEK_TOOLS", str(home / ".local/share/heretek-rigs/tools"))).resolve())
    secrets_dir = str(Path(os.environ.get("HERETEK_SECRETS", str(home / ".config/heretek-rigs/secrets"))).resolve())

    fleet_data = yaml.safe_load(Path(args.fleet).read_text())
    mcp_catalog = yaml.safe_load(Path(args.mcp).read_text())["servers"]
    if args.role not in fleet_data.get("roles", {}):
        die(f"unknown role {args.role}")
    role = fleet_data["roles"][args.role]
    member_id = args.member or args.role
    session = f"{args.pod}-{member_id}@{args.rig}"
    seat_dir = str(openrig_home / "state/pi" / session)
    out_dir = Path(args.out).resolve() if args.out else Path(seat_dir) / "agent"
    charter_path = Path(args.charter) if args.charter else Path("specs/agents") / role["domain"] / args.role / "guidance/role.md"
    if not charter_path.exists():
        die(f"missing charter {charter_path}")

    files = build_seat_files(
        role_id=args.role,
        rig_id=args.rig,
        pod_id=args.pod,
        member_id=member_id,
        fleet_data=fleet_data,
        mcp_catalog=mcp_catalog,
        tools_dir=tools_dir,
        secrets_dir=secrets_dir,
        seat_dir=seat_dir,
        charter_text=charter_path.read_text(),
        model_provider=args.model_provider,
        model_id=args.model_id,
        allow_missing_secrets=args.allow_missing_secrets,
        check_secret_fs=True,
    )

    if args.dry_run:
        print(json.dumps(files, indent=2, ensure_ascii=False))
        return

    for rel, body in files.items():
        p = out_dir / rel
        p.parent.mkdir(parents=True, exist_ok=True)
        content = body if isinstance(body, str) else json.dumps(body, indent=2, ensure_ascii=False) + "\n"
        p.write_text(content)
        os.chmod(p, 0o600)
    (Path(seat_dir) / "sessions").mkdir(parents=True, exist_ok=True)
    print(f"rendered {session} -> {out_dir}")


if __name__ == "__main__":
    main()

#!/usr/bin/env python3
"""seed-rig.py — Seed every Pi seat declared in a rig.yaml, pod fragment, or member fragment.

Invokes scripts/render-seat.py once per seat. Run BEFORE `rig up`, `rig expand`, or `rig add`.
"""
import os
import shutil
import sys

try:
    import yaml
except ImportError:
    if shutil.which("uv") and not os.environ.get("_HERETEK_UV_REEXEC"):
        os.environ["_HERETEK_UV_REEXEC"] = "1"
        os.execvp("uv", ["uv", "run", "--quiet", "--with", "pyyaml", "--with", "jsonschema", "python3", *sys.argv])
    raise

import argparse
import re
import subprocess
from pathlib import Path

USAGE = """usage: seed-rig.py <rig.yaml | pod-fragment.yaml | member-fragment.yaml> [--rig <rig-id>] [--pod <pod-id>] [--dry-run] [--allow-missing-secrets]
  rig.yaml          seeds every member of every pod (rig id = name:)
  pod fragment      needs --rig (the rig you will rig expand into)
  member fragment   needs --rig and --pod (the target of rig add)"""


def die(msg: str) -> None:
    print(f"error: {msg}", file=sys.stderr)
    sys.exit(2)


def role_of(m: dict) -> str:
    ref = m.get("agent_ref")
    if not ref:
        die(f"member {m.get('id')} has no agent_ref")
    cleaned = re.sub(r"^(local|path):", "", str(ref))
    return Path(cleaned).name


def main() -> None:
    if "--help" in sys.argv or "-h" in sys.argv:
        print(USAGE)
        sys.exit(0)

    parser = argparse.ArgumentParser(add_help=False)
    parser.add_argument("target", nargs="?")
    parser.add_argument("--rig")
    parser.add_argument("--pod")
    parser.add_argument("--dry-run", action="store_true")
    parser.add_argument("--allow-missing-secrets", action="store_true")
    args, unknown = parser.parse_known_args()
    if unknown or not args.target:
        print(USAGE)
        sys.exit(2)

    target_path = Path(args.target)
    if not target_path.exists():
        die(f"missing file {target_path}")
    doc = yaml.safe_load(target_path.read_text()) or {}

    seats = []
    if "pods" in doc:
        for p in doc["pods"]:
            for m in p.get("members", []):
                seats.append({"rig": doc["name"], "pod": p["id"], "member": m["id"], "role": role_of(m)})
    elif "members" in doc:
        if not args.rig:
            die("a pod fragment needs --rig")
        for m in doc["members"]:
            seats.append({"rig": args.rig, "pod": doc["id"], "member": m["id"], "role": role_of(m)})
    elif "agent_ref" in doc:
        if not args.rig or not args.pod:
            die("a member fragment needs --rig and --pod")
        seats.append({"rig": args.rig, "pod": args.pod, "member": doc["id"], "role": role_of(doc)})
    else:
        die(f"{target_path}: not a rig spec, pod fragment or member fragment")

    render_script = Path(__file__).resolve().parent / "render-seat.py"
    for s in seats:
        cmd = [
            sys.executable,
            str(render_script),
            "--role",
            s["role"],
            "--rig",
            s["rig"],
            "--pod",
            s["pod"],
            "--member",
            s["member"],
        ]
        if args.dry_run:
            cmd.append("--dry-run")
        if args.allow_missing_secrets:
            cmd.append("--allow-missing-secrets")
        if args.dry_run:
            proc = subprocess.run(cmd, stdout=subprocess.DEVNULL)
            if proc.returncode != 0:
                sys.exit(proc.returncode)
            print(f"ok {s['pod']}-{s['member']}@{s['rig']}")
        else:
            proc = subprocess.run(cmd)
            if proc.returncode != 0:
                sys.exit(proc.returncode)

    print(f"seeded {len(seats)} seat(s)")


if __name__ == "__main__":
    main()

#!/usr/bin/env bash
# bootstrap-pi-seats.sh — Provision $OPENRIG_HOME/state/pi/<session>/agent/ for Muse Spark 1.3 Contributor via OpenCode Go.

# Wrapper around scripts/seed-rig.py supporting:
#   ./scripts/bootstrap-pi-seats.sh [--rig <rig-slug> | --all] [--dry-run] [--strict-secrets]
set -euo pipefail

REPO_ROOT="$(cd "$(dirname "${BASH_SOURCE[0]}")/.." && pwd)"
cd "${REPO_ROOT}"

OPENRIG_HOME="${OPENRIG_HOME:-$HOME/.openrig}"
TARGET_RIG="all"
DRY_RUN="false"
ALLOW_MISSING="--allow-missing-secrets"

while [[ $# -gt 0 ]]; do
  case "$1" in
    --rig) TARGET_RIG="$2"; shift 2 ;;
    --all) TARGET_RIG="all"; shift ;;
    --dry-run) DRY_RUN="true"; shift ;;
    --strict-secrets) ALLOW_MISSING=""; shift ;;
    --help|-h)
      echo "Usage: $0 [--rig <rig-slug> | --all] [--dry-run] [--strict-secrets]"
      exit 0
      ;;
    *) echo "Unknown arg: $1" >&2; exit 2 ;;
  esac
done

ARGS=()
if [[ "${DRY_RUN}" == "true" ]]; then
  ARGS+=("--dry-run")
fi
if [[ -n "${ALLOW_MISSING}" ]]; then
  ARGS+=("${ALLOW_MISSING}")
fi

TOTAL=0
if [[ "${TARGET_RIG}" == "all" ]]; then
  for rfile in rigs/*/rig.yaml; do
    OUT=$(python3 "${REPO_ROOT}/scripts/seed-rig.py" "${rfile}" "${ARGS[@]}")
    COUNT=$(printf '%s\n' "${OUT}" | awk '/^seeded / {print $2}')
    TOTAL=$((TOTAL + ${COUNT:-0}))
  done
  if [[ -f "rigs/heretek-omni-fleet/rig.all-51.yaml" ]]; then
    OUT=$(python3 "${REPO_ROOT}/scripts/seed-rig.py" "rigs/heretek-omni-fleet/rig.all-51.yaml" "${ARGS[@]}")
    COUNT=$(printf '%s\n' "${OUT}" | awk '/^seeded / {print $2}')
    TOTAL=$((TOTAL + ${COUNT:-0}))
  fi
else
  OUT=$(python3 "${REPO_ROOT}/scripts/seed-rig.py" "rigs/${TARGET_RIG}/rig.yaml" "${ARGS[@]}")
  COUNT=$(printf '%s\n' "${OUT}" | awk '/^seeded / {print $2}')
  TOTAL=$((TOTAL + ${COUNT:-0}))
fi

if [[ "${DRY_RUN}" == "true" ]]; then
  echo "bootstrap-pi-seats: [DRY-RUN] would provision ${TOTAL} Pi seat directories under ${OPENRIG_HOME}/state/pi"
else
  echo "bootstrap-pi-seats: provisioned ${TOTAL} Pi seat directories under ${OPENRIG_HOME}/state/pi"
fi

"""Unit tests for scripts/render-seat.py output contract (no daemon, no network)."""
import json
import os
import subprocess
import sys
import tempfile
import unittest
from pathlib import Path

REPO_ROOT = Path(__file__).resolve().parent.parent
RENDER_SCRIPT = REPO_ROOT / "scripts/render-seat.py"


class TestRenderSeat(unittest.TestCase):
    def setUp(self):
        self.tmp_dir = tempfile.TemporaryDirectory()
        self.secrets = Path(self.tmp_dir.name) / "secrets"
        self.secrets.mkdir(mode=0o700)
        key_file = self.secrets / "opencode-go.key"
        key_file.write_text("dummy")
        os.chmod(key_file, 0o600)
        self.env = {
            **os.environ,
            "HERETEK_SECRETS": str(self.secrets),
            "HERETEK_TOOLS": "/opt/hr-tools",
            "OPENRIG_HOME": "/tmp/hr-openrig",

    def tearDown(self):
        self.tmp_dir.cleanup()

    def render(self, *args):
        proc = subprocess.run(

            env=self.env,
            capture_output=True,
            text=True,

def utf16_key(s: str):
    return [int.from_bytes(s[i].encode("utf-16-le"), "little") for i in range(len(s))]


def compute_configuration_id(mapping: dict) -> str:

def compute_package_digest(integrity_files: dict) -> dict:
    lines = []
    for k in sorted(integrity_files.keys(), key=utf16_key):
        quoted = json.dumps(k, ensure_ascii=False)
        lines.append(f"{quoted}\t{integrity_files[k]}\n")
    val = hashlib.sha256("".join(lines).encode("utf-8")).hexdigest()
    return {
        "algorithm": "sha256",
        "value": val,
        "coverage": "openrig.package-digest/v1",
    }


def tree_hash(d: Path) -> str:
    h = hashlib.sha256()

    def walk(cur: Path):
        for entry in sorted(cur.iterdir(), key=lambda p: p.name):
            if entry.is_dir():
                walk(entry)
            else:
                rel = entry.relative_to(d).as_posix()
                h.update(rel.encode("utf-8") + b"\0")
                h.update(entry.read_bytes())

    walk(d)
    return "sha256:" + h.digest().hex()

def compute_configuration_id(mapping: dict) -> str:

def compute_package_digest(integrity_files: dict) -> dict:
    lines = []
    for k in sorted(integrity_files.keys(), key=utf16_key):

## 7. Gotchas Checklist (Re-Read Before Every Milestone)

1. `rig spec validate` and `rig bundle check` work offline; `rig agent validate` and `rig spec preflight` require `rig daemon start --no-kernel`.
2. `rig bundle check <dir> --json` returns a JSON array `[]` (not an object); `jq 'length'` is `0` when clean.
3. `runtime: opencode` passes `rig spec validate` and fails only in `rig spec preflight`. Always use `runtime: pi`.
4. OpenRig strips `OPENCODE_API_KEY` from `runtime: pi` seats. Credentials reach Pi via `<agentDir>/auth.json` (`0600`) `"!cat <SECRETS>/opencode-go.key"`.
5. `@gotgenes/pi-permission-system@41.0.0` evaluates maps with last-matching-rule-wins semantics. `"*..*": "deny"` MUST be the last key in `path_write` and `path`.
6. Mutating extension tools (`code_rewrite`, `lsp_rename`, `lsp_code_actions` from `pi-lsp-extension@1.4.0`) are `ToolKind = "extension"` and bypass `path_write`; keep them explicitly set to `"deny"` in every seat's permission map.
7. Never use `guidance_merge` for role charters on shared `<cwd>` seats; `scripts/render-seat.py` writes the role charter to `<agentDir>/AGENTS.md`.
8. Never include `plugins: [{source: {kind: local, path: "openrig-home:..."}}]` in `specs/agents/_shared/agent.yaml` — `bundle-check.ts:98` rejects it as outside the bundle folder, and `PiRuntimeAdapter.projectEntry` skips plugins anyway.
9. `rig expand` requires the runtime rig ULID (`rigId` from `rig ps --json`), not the rig name. Always pass an absolute `--rig-root "$PWD"`.
10. Never modify `LICENSE.md`.
